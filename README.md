# Flutter Practice

A collection of Flutter mini-projects and exercises covering widgets, layouts, state management, and navigation — part of my journey toward becoming a Flutter developer.

## 📚 What's Inside

- Dart fundamentals (variables, functions, OOP, null safety)
- Core widgets: `Row`, `Column`, `Container`, `Stack`, `ListView`
- `StatelessWidget` vs `StatefulWidget`
- Navigation between screens
- Form handling and validation
- API integration
- State management (Provider)

## 🛠️ Tech Stack

- **Language:** Dart
- **Framework:** Flutter
- **IDE:** VS Code

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/nikhilbishnoi007/flutter-practice.git
   ```
2. Navigate to a project folder
   ```bash
   cd flutter-practice/<project-folder>
   ```
3. Get dependencies
   ```bash
   flutter pub get
   ```
4. Run the app
   ```bash
   flutter run
   ```
